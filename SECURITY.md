# Security policy

## Supported versions

Only the latest release gets security fixes. Miautify is young, so please update
to the latest release before reporting.

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately
through GitHub instead: on the [Security
tab](https://github.com/innocentmiau/Miautify/security) of this repository,
click "Report a vulnerability". Only the maintainer can see the report.

Please include:

- what you found and what it lets an attacker do,
- how to reproduce it (for example a sample mp3 or image file),
- the Miautify version and your operating system.

Miautify is a hobby project run by one person, so there's no guaranteed response
time, but I'll reply as soon as I can. If you'd like, you'll be credited in the
changelog when the fix is released.

## Scope

In scope: anything that lets a music file, a cover image, or the app's own page
read or change files it shouldn't, run code, or crash the app on purpose.

Out of scope: problems that need someone to already control your computer or
your user account.
